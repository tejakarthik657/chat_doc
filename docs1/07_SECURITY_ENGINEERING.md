# Phase 7: Security Engineering (VeriDoc Synapse)

> *"In clinical research and healthcare software, security is not an afterthought or an add-on plugin. Security is an architectural guarantee enforced from the edge down to the database socket."*

---

## 46. Application Security
*OWASP Top 10, secure coding, input sanitization.*

### Defending the OWASP Top 10:
1. **A01: Broken Access Control**: Enforced through stateless JWT verification and tenant scoping (`project_id`) on all database operations.
2. **A03: Injection (SQL & Command)**: All SQL queries generated by the Inbound Database MCP are passed through an **Abstract Syntax Tree (AST) validation parser** before reaching the database connection.
3. **A05: Security Misconfiguration**: Strict HTTP security headers injected on all FastAPI responses via `SecurityHeadersMiddleware`:
   - `X-Frame-Options: DENY` (Eliminates clickjacking).
   - `X-Content-Type-Options: nosniff` (Prevents MIME sniffing attacks).
   - `Strict-Transport-Security: max-age=31536000; includeSubDomains` (Forces HTTPS).

---

## 47. API Security
*Rate limiting, API keys, authentication, request validation.*

- **Rate Limiting**: In-process Token Bucket rate limiter per key (`core/groq_resilience.py`) and IP-level request throttling.
- **Request Size Limiting**: `RequestSizeLimitMiddleware` terminates any incoming request payload exceeding **100MB** at the socket layer, protecting against memory exhaustion denial-of-service (DoS) attacks.
- **Strict Pydantic Validation**: All request bodies must strictly conform to Pydantic v2 schemas; unvalidated fields are rejected with HTTP 422.

---

## 48. Data Security
*Encryption at rest, encryption in transit, sensitive data protection.*

- **In Transit**: 100% TLS 1.3 encryption across all client-to-backend and backend-to-database connections.
- **At Rest**: Local storage volumes utilize operating system volume encryption (AES-256). MongoDB Atlas clusters enforce encrypted storage engines.
- **Data Minimization**: In Cloud LPU mode, only the top 3–5 matching text chunks (~500 tokens) are transmitted; the entire raw PDF remains within the local perimeter.

---

## 49. Infrastructure Security
*Network security, firewall rules, secrets management, access control.*

- **Zero-Secret Hardcoding**: All secrets (JWT signing keys, MongoDB URIs, Groq API key pools) are injected at runtime via environment variables managed by Pydantic's `BaseSettings`.
- **SSRF Defense**: The autonomous web crawler verifies that resolved target IP addresses are not within private RFC 1918 ranges or cloud metadata endpoints (`169.254.169.254`).

## 51. Privacy & Compliance
*Consent, data retention, audit trails, regulatory requirements (HIPAA & 21 CFR Part 11).*

- **FDA 21 CFR Part 11 Compliance**: Every outbound operational action (Slack alerts, EDC protocol holds) generates an immutable, cryptographically timestamped log entry in `action_logs` recording the user ID, timestamp, and target payload.
- **HIPAA Data Residency**: The **Air-Gapped Private Mode** routes all inference to on-premise Ollama instances; zero bytes ever cross the public internet.
